# Cybersecurity Projects

Welcome to my cybersecurity projects repository! This is a curated collection of my work related to cryptography, network security, threat detection, and AI applications in security.

Below you will find links to the individual repositories for each project, along with a brief description of what they do.

---

### 🛡️ [ZK Vault](https://github.com/neerajsait/ZK-Vault)
**Zero-Knowledge Secure Vault for Private Data Storage**
A zero-knowledge inspired encrypted vault designed around the principle that sensitive plaintext should never need to reach the backend. Cryptographic operations are performed locally while the Flask backend handles encrypted data, authentication workflows, quotas, and business logic.
- **Tech Stack:** Python, Flask, MySQL, Redis, Cryptography

### 🌐 [Network Monitor](https://github.com/neerajsait/Network-Monitor)
**Real-Time Network Monitoring Dashboard**
A real-time network monitoring and host-based intrusion detection system. It captures network traffic and combines packet inspection, DLP-style pattern detection, and WebSocket streaming to provide a live security dashboard.
- **Tech Stack:** Python, Flask, Scapy, Socket.IO, JavaScript/HTML

### 🎣 [Phishing-URL](https://github.com/neerajsait/Phishing-URL)
**Phishing URL Detection System**
A project focused on analyzing and identifying malicious and phishing URLs. It leverages security principles and data analysis to detect deceptive web links designed to steal user credentials.
- **Tech Stack:** Python, Security Analysis

### 📄 [termpaper](https://github.com/neerajsait/termpaper)
**Python-Based Document Automation**
A Python-based document automation tool tailored for academic and research workflows. It streamlines the creation and formatting of term papers, ensuring consistency and adherence to required document standards.
- **Tech Stack:** Python, Automation

### 👤 [Face-Recognition](https://github.com/neerajsait/Face-Recognition)
**AI-Powered Face Recognition Application**
A face recognition web application utilizing JavaScript and AI APIs. It explores the intersection of computer vision, artificial intelligence, and biometric security to identify and verify individuals in real-time.
- **Tech Stack:** JavaScript, Computer Vision, AI APIs
